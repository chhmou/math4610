Course description

Fundamental techniques for the numerical solution of problems in science and engineering: floating-point arithmetic, error analysis, root finding, numerical linear algebra, interpolation, numerical differentiation and integration, and the numerical solution of ordinary differential equations. Both theory and implementation are emphasized, with examples drawn from applied fields.

Prerequisites. MATH 2270 (Linear Algebra), MATH 2280 (Differential Equations), and experience programming in MATLAB, Python, or a similar language.

Tentative schedule

  • Introduction; computational experiments in MATLAB/Python
  • IEEE floating-point arithmetic and error analysis
  • Linear algebra review; matrix and vector operations
  • Gaussian elimination and pivoting
  • Conditioning; LU and Cholesky factorizations
  • Sparse matrices
  • Root finding: bisection, Newton, secant; roots of polynomials
  • Interpolation: polynomials, splines, Bézier curves
  • Numerical integration: Newton–Cotes, Gaussian quadrature
  • Numerical differentiation
  • Iterative methods; Markov chains and PageRank
  • Power method, SVD, and least squares
  • Monte Carlo methods and randomness
  • The fast Fourier transform
  • Special topics (time permitting)

Topics are tentative and subject to change; updates will be announced in class and on Canvas.

Final project

Each student chooses one of three project options and studies the implementation and analysis of a numerical method, culminating in a written report and an in-class presentation. Presentations take place during the last three class meetings: Mon, Dec 7; Wed, Dec 9; and Fri, Dec 11.

Requirements

  • Choose one of the three options above; the project guidelines describe how to confirm your choice.
  • Written report (PDF) covering the problem, the numerical method, its implementation, numerical results (figures and tables), an error or convergence study, and conclusions, with references.
  • Code in MATLAB or Python that reproduces every figure and table in the report, submitted together with the report.
  • In-class presentation on Dec 7, 9, or 11; the presentation schedule and time limit will be announced in class.
  • Report and code due: to be announced.
  • Cite all sources you use, including books, papers, and online code.

Project documents are posted here as PDFs; each link goes live once the file is uploaded.

Textbooks & software

Suggested textbooks. Numerical Analysis, 10th ed., Burden & Faires; and Numerical Methods: Design, Analysis, and Computer Implementation of Algorithms, Greenbaum & Chartier.

Software. MATLAB or Python (NumPy/SciPy/Matplotlib) is recommended for implementing algorithms and completing assignments.
