Course description

Fundamental techniques for the numerical solution of problems in science and engineering: floating-point arithmetic, error analysis, root finding, numerical linear algebra, interpolation, numerical differentiation and integration, and the numerical solution of ordinary differential equations. Both theory and implementation are emphasized, with examples drawn from applied fields.

Prerequisites. MATH 2270 (Linear Algebra), MATH 2280 (Differential Equations), and experience programming in MATLAB, Python, or a similar language.

Tentative schedule

  • Introduction; computational experiments in MATLAB/Python
  • IEEE floating-point arithmetic and error analysis
  • Linear algebra review; matrix and vector operations
  • Gaussian elimination and pivoting
  • Conditioning; LU and Cholesky factorizations
  • Sparse matrices
  • Root finding: bisection, Newton, secant; roots of polynomials
  • Interpolation: polynomials, splines, Bézier curves
  • Numerical integration: Newton–Cotes, Gaussian quadrature
  • Numerical differentiation
  • Iterative methods; Markov chains and PageRank
  • Power method, SVD, and least squares
  • Monte Carlo methods and randomness
  • The fast Fourier transform
  • Special topics (time permitting)

Topics are tentative and subject to change; updates will be announced in class and on Canvas.

Final project

Each student chooses one of the three projects below and submits a written report with MATLAB code. Presentations take place in class during the last three class meetings: Mon, Dec 7; Wed, Dec 9; and Fri, Dec 11. The report and code are due Fri, Dec 18, 11:59 p.m., on Canvas.

Requirements

  • Choose one of the three projects above.
  • Written report (PDF), typeset in LaTeX or Word, with the derivations, tables, figures, and a brief discussion of the results for each problem.
  • Code in MATLAB, submitted as a zip file: one script for each problem (Q1.m, Q2.m, Q3.m) that produces its figures and tables, and a short README file.
  • In-class presentation on Dec 7, 9, or 11. Present the problem, your main results, and your conclusions; the work need not be finished. The schedule will be posted on Canvas.
  • Report and code due Fri, Dec 18, 11:59 p.m., on Canvas. The report may take into account comments made at the presentation.
  • You may discuss the project with others, but your code and report must be your own. Cite all sources you use.

Each project is graded out of 100 points: three problems (70), code (10), written report (10), and presentation (10), with a 10-point bonus problem. See the project PDFs for details.

Textbooks & software

Suggested textbooks. Numerical Analysis, 10th ed., Burden & Faires; and Numerical Methods: Design, Analysis, and Computer Implementation of Algorithms, Greenbaum & Chartier.

Software. MATLAB or Python (NumPy/SciPy/Matplotlib) is recommended for implementing algorithms and completing assignments. The final project must be done in MATLAB.
